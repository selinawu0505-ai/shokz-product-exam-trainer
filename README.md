# 韶音产品考试通关训练营

根据 2024 年产品考试题型与产品学习资料整理的游戏化自测网页。

## 功能

- 175 道动态题库，其中包含 58 道企业文化题
- 单选、多选、判断、填空、综合填空、简答六种题型
- 按题型闯关、按产品闯关与企业文化专区
- 2026 品牌手册速记、六大文化主题专项训练
- 今日混合练习、错题复仇与答案解析
- 60 分钟、32 题、100 分制模拟考试
- 内置 80 分备考冲刺手册

## 使用

直接访问 GitHub Pages 地址即可开始练习。学习记录保存在使用者自己的浏览器中，无需登录。

本项目用于内部学习与考试复习，请勿将题目和资料用于商业用途。
